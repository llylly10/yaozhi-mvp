# 中华医学会杂志社 教育使用授权申请 + 无授权替代方案

> 背景：中华医学会及中华医学期刊网版权声明明确禁止"商业性目的的转载、复制、制作数据库"。
> 临床指南/专家共识全文批量入库恰好触碰该条款，因此申请授权是正路；未获批前用"出处+要点摘要"方案（合法且已在方案内）。

---

## 申请函模板

**主题：关于临床指南与专家共识内容用于药学教育软件校内试点的授权申请**

中华医学会杂志社：

您好！我们是【学校名称】【学院名称】学生团队（指导教师：【】，联系方式：【】），开发药学专业学习辅助软件"药知"，用于校内教学试点（Datawhale 星跃三期竞赛项目，非商业用途）。

软件功能：学生完成药理学练习后，系统依据权威指南与共识对其错误进行归因，并展示学习建议。我们希望申请贵会发布的临床指南与专家共识的以下使用方式：

1. **引用粒度**：不做指南全文收录。软件仅在涉及相应主题时，展示"依据《指南名称》（发布年份）推荐……"式的一段要点转述（每处不超过 200 字），并显著标注指南名称、发布机构与年份；
2. **使用范围**：仅限校内教学试点（约 30 名学生）与竞赛演示，非商业用途；
3. **数据管理**：要点转述文本存储于校内演示环境，可接受贵会随时要求下架。

如贵会认可，希望确认上述转述式引用是否需要书面授权，以及贵会建议的署名格式。我们也欢迎贵会提出其他合作条件。

【学校/团队名称】【日期】

## 无授权替代方案（默认执行，合法）

对每份要引用的指南/共识，只入库以下结构化记录（不含原文表达）：

```
{
  "指南名称": "中华医学会《XXX 临床诊疗指南》(2024)",
  "出处": "中华医学会杂志社 + 原文链接",
  "要点摘要": "顾问用自己的话写的 3-5 条推荐要点",
  "原文链接": "https://…"
}
```

法律逻辑：指南中的医学推荐意见（如"闭角型青光眼患者应避免使用抗胆碱药物"）属于事实与思想，顾问转述后不构成对原文表达的复制；原文链接供溯源。此方案无需授权即可执行。
