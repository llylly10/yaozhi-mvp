# 药理题库章节映射审校

## 目标

在不直接替代药理顾问的前提下，先用正确答案信号消除错误选项造成的假并列，再导出剩余并列、未映射和单映射抽查清单。

## 边界

- 题干明确命中时，正确答案不得覆盖题干结论。
- 正确答案只用于打破已有候选章节之间的并列。
- 局麻药、抗癫痫药、抗组胺药因大纲缺章，继续保留未映射。
- 先dry-run和生成审校报告，不直接写库。
